# Fake Traveler+（虚拟旅者+）

用于**测试自己或团队开发的 App** 的 Android 模拟定位工具，基于开源项目
[FakeTraveler](https://github.com/mcastillof/FakeTraveler)（GPL-3.0，上游提交 `ff7ddfd`）修改。

它使用 Android 官方的模拟位置接口（`LocationManager.addTestProvider`）。系统会把这些位置标记为模拟位置（`Location.isMock()` 为 `true`），本工具**不会**隐藏这个标记。

## 相比上游新增的功能

| 功能 | 说明 |
| --- | --- |
| 后台持续模拟 | 改为前台服务（Foreground Service，类型为 `location`），切到后台或关闭屏幕后仍会继续推送位置。通知栏显示当前坐标，可以**暂停/继续/停止**。 |
| 暂停 | 暂停后停在当前位置，继续推送同一坐标，速度为 0，方便测试“停留”场景。 |
| 路线模式 | 在地图上依次长按添加途经点，可撤销或清空。设定速度（km/h）后沿折线匀速移动，并输出与行进方向一致的 `bearing`（方位角）和 `speed`。循环方式有三种：**走一次后停在终点 / 循环（回到起点再开始） / 往返**。界面显示途经点数、总距离和预计耗时。 |
| 收藏 | ★ 按钮可以收藏当前地点或当前路线，之后一键载入。长按列表项可删除。 |
| 单点模式即时跳转 | 模拟运行中长按地图，位置会立即跳过去，适合测试地理围栏（Geofence）的进入和离开。 |
| 修正 | 上游“按速度模拟”的速度单位算错了（多除了 1000），已改为 m/s；中文翻译也做了修正。 |
| 中文界面 | 界面固定为简体中文，不随手机系统语言变化。 |
| 高德底图 | 默认使用高德街道图，也可在 ⚙ 设置页的下拉选单里改成高德卫星图、OpenStreetMap 或自定义名称，切换后返回地图就会生效。高德底图使用 GCJ-02 坐标，App 会在显示时自动换算（`assets/chinamaps.js`），所以在地图上点的位置、输入框里的数字和模拟出去的位置，都是标准 GPS 的 WGS-84 坐标。 |

上游原有的单点模拟、按固定步长漂移、模拟次数和间隔、地图来源等设置都保留了（⚙ 设置页）。

## 下载与安装

1. 打开本仓库的 **Actions** 页面 → 左侧 **Android** → 点最新一次成功（绿色勾）的运行。
2. 在页面底部的 **Artifacts** 区域下载 `app-debug.apk`（需要登录 GitHub）。
3. 传到手机上安装，需要允许“安装未知来源应用”。
   每次 CI 构建使用的调试签名都不同，所以**安装新版本前要先卸载旧版**（收藏会一并清空）。
4. 在手机上：**设置 → 关于手机**，连续点“版本号” 7 次开启开发者选项；再到**开发者选项 → 选择模拟位置信息应用**，选中 **虚拟旅者+**。
5. 第一次按“应用”时，请允许**定位**权限（Android 14 起，定位类前台服务必须有这个权限）和**通知**权限。

应用 ID 是 `cl.coders.faketraveler.plus`，可以和上游 FakeTraveler 同时安装。

## 使用提示

- 地址搜索使用 OSM 的 Nominatim 服务，在中国大陆可能连不上。连不上时，可以直接在地图上找位置，或者输入坐标。
- 高德底图是网页版公开的底图地址，非官方 API，适合内部测试，不适合商用。
- 位置偶尔在真实位置和模拟位置之间跳动时，可以到系统**定位服务**里关闭“WLAN 扫描”和“蓝牙扫描”，避免它们干扰。
- 路线在运行中修改不会立即生效，需要停止后重新按“应用”。
- 路线位置每秒更新一次。单点模式按设置页的“间隔秒数”更新。
- 模拟期间会持有 CPU 唤醒锁（Partial WakeLock），以便关屏后仍按时推送位置，因此会比较耗电，用完请按“停止”。

## 构建

```bash
cd FakeTravelerPlus
./gradlew testDebugUnitTest assembleDebug
```

需要 JDK 21 和 Android SDK（compileSdk 36）。路线计算逻辑（`RouteSimulator`）有 JVM 单元测试：`app/src/test/`。
