**Gatehouse 1.1.0：连接失败时，直接告诉你为什么。**

## 新功能：连接日志

每次连接服务器，Gatehouse 都会记录完整过程：查找地址 → 建立网络连接 → 服务器应答 → 加密协商 → 核对服务器身份 → 登录，每一步都有耗时和结果。连接失败时，它会自动判断原因，并列出可以怎么做。能识别的情况包括：

- **网络**：地址找不到（常见于没连 VPN）、端口没开或被防火墙拦截、网络不通（含 macOS「本地网络」权限）、服务器立即断开（例如多次登录失败后被暂时封禁）。
- **服务器**：端口上运行的不是 SSH（例如填成了网页服务的端口）、加密方式过旧（并判断开启“旧版算法”是否真的有用）、服务器身份改变。
- **登录**：用户名或密码错误、服务器不允许用密码登录、密钥没有授权、SSH 代理没有运行或里面没有密钥、需要两步验证、等待输入时登录超时。
- **其他**：跳板机连不上或已被删除、跳板机连不到目标服务器、连接中途断开。

**在哪里看**

- 「保存并测试」失败时，连接日志会自动弹出。
- 主机卡片上会显示红色的失败原因，点一下就能打开。
- 终端、文件、隧道、安装密钥出错时，点「查看原因」。
- 主机右键菜单（或卡片上的 ⋯）→「连接日志…」。

**发给管理员**：点「复制诊断报告」，结论、每一步和技术日志都会复制下来。默认隐藏服务器地址、用户名、所有 IP，以及服务器自己发来的文字；需要时可以勾选保留。

**隐私**：日志只保存在你的 Mac 上（仅你自己可读），从不记录密码、口令、验证码或私钥；删除主机时，它的记录一并删除。Claude 只会收到一句不含地址的原因，并被提示请你查看连接日志。

## 改进与修复

- **更快给出结论**：地址错误或端口不通时，20 秒内就会报告（以前最长要等 3 分钟）。
- **已保存的密码**：只有在服务器明确拒绝登录时才会清除；网络故障不会再误删密码；两步验证中只有第二步（验证码）出错时，也不会删掉正确的密码。
- **取消连接**：删除或修改正在连接的主机时会立即停止，相关的确认窗口也会自动关闭。
- **键盘操作**：按 Esc 只关闭最上层的窗口；对话框打开时自动获得键盘焦点。
- **中文界面**：「关闭」档位的说明改为中文；「保存并测试」时别名框不再误显示为红色；左下角暂停开关的说明不再被截断，暂停状态改用琥珀色。
- **首次打开说明**：已更新为适用于 macOS 15 及以后的步骤（见下文）。

## 下载

| 你的 Mac | 下载 |
| --- | --- |
| Apple 芯片（M1 及以后） | `Gatehouse-1.1.0-arm64.dmg` |
| Intel 芯片 | `Gatehouse-1.1.0-x64.dmg` |

需要 macOS 12 或更新版本。远端服务器**无需安装任何东西**，只要运行 SSH 服务即可。

**从 1.0.0 升级**：把新版拖进“应用程序”替换旧版即可，主机、密钥和设置都会保留。新版第一次打开时，macOS 可能会再拦一次（步骤同下）；钥匙串可能询问授权，输入 Mac 登录密码后点“始终允许”。

**首次打开**：应用只有临时签名（ad-hoc），未经 Apple 公证，macOS 会先拦一下：

1. 双击 Gatehouse，出现无法打开的提示时点“完成”（不要点“移到废纸篓”）。
2. 打开“系统设置 → 隐私与安全性”，在下方“安全性”里点 Gatehouse 旁边的“仍要打开”，用登录密码或 Touch ID 确认。这个按钮只在被拦下后约一小时内出现。

- macOS 14 及更早版本也可以在“应用程序”中按住 Control 点按 Gatehouse，选择“打开”。
- 仍然打不开（例如提示“已损坏”）：在“终端”执行 `xattr -dr com.apple.quarantine /Applications/Gatehouse.app`。

**校验完整性（可选）**：把 `SHA256SUMS.txt` 和 DMG 放在同一目录，执行
`shasum -a 256 -c SHA256SUMS.txt --ignore-missing`，显示 `OK` 即文件完整。
