# 电源助手（PowerHelper）

Windows 小工具：设置电脑闲置多久后自动**关闭屏幕、睡眠、休眠**，设置电源键与合盖动作，并提供**只关屏幕、电脑继续运行**的“立即息屏”（可用快捷键 `Ctrl+Alt+S`）。

## 功能

| 项目 | 说明 |
| --- | --- |
| 关闭屏幕 / 进入睡眠 / 进入休眠 | 闲置多久后自动执行。笔记本电脑可分别设置“插电时”和“使用电池时”，台式机只显示一栏。 |
| 按下电源键时 | 不执行任何操作 / 睡眠 / 休眠 / 关机 / 关闭显示器。“现代待机”电脑不提供“关闭显示器”（见下方说明）。 |
| 合上盖子时 | 笔记本电脑才显示。设为“不执行任何操作”时，合盖只关屏幕。 |
| 一键设为“息屏⇄亮屏” | 非“现代待机”电脑才显示：按一下电源键只关闭屏幕，电脑继续运行；再按一下电源键、动鼠标或按任意键即可亮屏。 |
| 立即息屏 | 只关闭屏幕，电脑继续运行；动鼠标或按任意键即可亮屏。可在桌面创建“息屏”快捷方式，双击或按 `Ctrl+Alt+S` 即可息屏，不需要程序常驻后台。 |
| 启用休眠 | 休眠功能未开启时，可一键开启（会弹出管理员权限确认）。 |
| 组策略提示 | 医院 / 公司 IT 部门统一锁定的项目会显示提示，避免“改了却没效果”。 |

所有设置都直接写入 Windows **当前使用中的电源计划**，与“设置 → 系统 → 电源”、“控制面板 → 电源选项”里的是同一组设置。
点“应用”后立即生效，**程序不需要常驻后台**，关掉也不影响。

## 系统要求

- Windows 10（1903 及以后版本）或 Windows 11
- 使用系统自带的 .NET Framework 4.8，无需另外安装任何东西

## 下载与使用

1. 打开本仓库的 **Actions** 页面 → 左侧 **Build** → 点最新一次成功（绿色勾）的运行。
2. 页面底部 **Artifacts** 区域点击 `PowerHelper.exe` 下载（需登录 GitHub）。
3. 双击运行。程序没有数字签名，首次运行若出现“Windows 已保护你的电脑”（SmartScreen），点 **更多信息 → 仍要运行**。
4. 调整选项后点 **应用**；或直接点 **一键设为“息屏⇄亮屏”**（只修改电源键，其他选项不变）。

## “现代待机”电脑的电源键

大多数较新的 Windows 11 笔记本电脑使用“现代待机”（Modern Standby / S0 Low Power Idle）。这类电脑上 Windows **不支持**让电源键只关闭屏幕（“设置 → 系统 → 电源和电池 → 盖子和电源按钮控件”里也没有这个选项）。
即使写入该设置也不会报错，但按电源键没有任何反应。本工具检测到“现代待机”时会隐藏该选项，并改为提供：

- **立即息屏 / `Ctrl+Alt+S` 快捷键**：只关闭屏幕。
- **合上盖子时 → 不执行任何操作**：合盖只关屏幕，开盖亮屏。

注意：部分“现代待机”电脑在屏幕关闭一段时间后，仍可能自行进入待机（后台程序暂停），视厂商与驱动而定，请实际测试。

## 常见问题

- **提示“没有权限修改电源设置”**：右键点击 `PowerHelper.exe` → 以管理员身份运行。
- **提示“由组织的组策略统一管理”**：该项目被 IT 部门锁定，需联系 IT 调整。
- **想恢复原来的电源键动作**：在“按下电源键时”选回原来的选项（修改前程序会显示当前值，可先记下），再点“应用”。
- **电源键显示“关闭显示器（此电脑不支持）”**：这是“现代待机”电脑上之前写入的无效设置，请改选其他选项（笔记本电脑通常为“睡眠”）并点“应用”。
- **`Ctrl+Alt+S` 没反应**：快捷键要在桌面“息屏”快捷方式建好后才生效，偶尔需要注销再登录一次；也可右键快捷方式 → 属性 → “快捷键”改成其他组合。
- **切换了电源计划后设置不见了**：本工具只修改当前使用中的电源计划；切换计划后重新设置一次即可。
- **“进入休眠”是灰色的**：休眠功能未开启，点“启用休眠”；若仍无法启用，可能是这台电脑（例如虚拟机）不支持休眠。

## 从源码编译

需要 .NET SDK（6 或以上，任何操作系统均可）：

```
dotnet build PowerHelper/PowerHelper.csproj -c Release
```

输出：`PowerHelper/bin/Release/net48/PowerHelper.exe`

每次推送代码，GitHub Actions 会在 Windows 上自动编译，并运行 `tests/smoke-test.ps1`（在真实 Windows 上读写电源设置并还原），再上传 exe。

## 技术说明

- 通过 Windows 电源 API（`powrprof.dll`：`PowerReadACValueIndex` / `PowerWriteACValueIndex` 等）读写设置，不解析 `powercfg` 的文字输出，因此中文、日文、英文 Windows 都能正常使用。
- 涉及的电源设置：`VIDEOIDLE`（关闭屏幕）、`STANDBYIDLE`（睡眠）、`HIBERNATEIDLE`（休眠）、`PBUTTONACTION`（电源键，4 = 关闭显示器）、`LIDACTION`（合盖）。
- “现代待机”由 `GetPwrCapabilities` 的 `AoAc` 字段判断。
- “立即息屏”发送 `WM_SYSCOMMAND / SC_MONITORPOWER`（延迟 1 秒，避免放开按键或鼠标时立刻又亮屏）；桌面快捷方式运行 `PowerHelper.exe /screenoff`，程序本体会复制到 `%LOCALAPPDATA%\PowerHelper\`，避免移动或删除下载的文件后快捷方式失效。
