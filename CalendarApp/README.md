# 一览（OneGlance）—— iOS 日历与任务排程

> **不想签名？** 另有不需要签名、不用 Mac 的 [Scriptable 版](Scriptable/README.md)，功能大致相同。

直接读写 iPhone 系统的**日历**和**提醒事项**，所以和系统日历、iCloud、Google、Exchange 等所有账户**实时同步**，不会另存一份数据。
重点在于：一个画面看完一天的所有安排、少跳页、拖一下就能排程。

## 功能

| 视图 | 内容 |
| --- | --- |
| **日** | 顶部“托盘”：班次、全天日程、今天待办、逾期待办、已完成；下方时间轴。也可以切成**清单**：所有事项按时间排一列，中间标出空闲时段和“现在”。 |
| **周** | 7 天并排；每天显示班次、全天事项和待办数量；日程可以**跨天拖动**。 |
| **月** | 每天按排满程度上色（**负荷热力图**），显示班次简称、日程数、待办数；两班间隔太短会出现 ⚠︎；底部显示所选那天的明细和本月班次统计。 |
| **快速新增** | 屏幕底部常驻输入栏，输入一句话就能新增，送出前会先显示它理解成什么。 |
| **小组件** | 主屏幕（小 / 中 / 大）与锁定画面；可以在小组件上直接勾选完成待办。 |

### 操作方式

- **移动**：长按日程（或已定时的待办）后拖动；周视图里可以拖到别天。
- **改时长**：长按方块底边后上下拖动。
- **新建**：在时间轴空白处长按并往下拖出时长，或直接双击空白处。
- **排进时间轴**：长按托盘里的待办，拖到时间轴上的某个时间（也可以拖到上方日期条、周视图日期或月视图格子上）。
- **快捷操作**：长按待办 → 今天 / 推迟一天 / 下周 / 移到未排期 / 删除；清单模式下左滑完成、右滑推迟或删除。
- **缩放**：日视图双指捏合调整时间轴的疏密。
- **未排期**：没有日期的提醒事项收在托盘的「未排期」里，规划时从这里拖进当天。

### 快速新增语法

| 输入 | 结果 |
| --- | --- |
| `明天下午3点 开会 1小时` | 日程，明天 15:00–16:00 |
| `周五 10:30-12:00 门诊` | 日程 |
| `下周一 20:00-08:00 支援` | 跨夜日程，结束于次日 08:00 |
| `买药` | 待办，日期为当前所选那天 |
| `待办 明天3点 交报告 !!` | 定时待办，中优先级（`!` 低 / `!!` 中 / `!!!` 高） |
| `写论文 2小时` | 待办，预估 2 小时 |
| `明天 全天 学术会议` | 全天日程 |
| `周六 夜班` | 套用「夜班」班次模板 |
| `组会 周三 9点 #工作` | 写入名为「工作」的日历（或提醒事项列表） |

支持：今天 / 明天 / 后天 / 大后天、今晚 / 明早、周X / 下周X / 本周X / 星期X / 礼拜X、`10月20日`、`十月二十号`、`10/20`、`2026-10-20`、`20号`、`3天后`、上午 / 下午 / 晚上 / 凌晨、`3点半`、`七点一刻`、`am/pm`、`半小时`、`1.5h`、`90分钟`。
没写上午或下午时，1–6 点视为下午（`3点开会` → 15:00）；写成 `06:30` 则视为早上。
`12号床` 这类写法不会被当成日期。预览第一个标签（日程 / 待办）可以点一下来切换类型。

### 排班

- 设置里可以编辑**班次模板**（名称、简称、颜色、开始时间、时长，可跨夜；也可以设成全天，例如休息）。默认有白班、夜班、值班、休息。
- 月视图点「排班」→ 选班次 → 点日期即可排班；再点一次同一个班次就取消；「清除」可以删掉当天的班次。
- 班次就是普通的日历事件，系统日历里也看得到。建议在设置里点「建立『排班』专用日历」，方便单独显示或隐藏。
- 两班之间的休息时间少于设定值（默认 11 小时，可调整）时会提示。

## 安装到 iPhone（需要 Mac）

需要 **Xcode 16 或更新版本**，以及 iOS 17 或更新版本的 iPhone。

1. 在 Mac 上下载本仓库（GitHub 页面 **Code → Download ZIP**，或 `git clone`），用 Xcode 打开 `CalendarApp/OneGlance.xcodeproj`。
2. Xcode → Settings → Accounts，加入你的 Apple ID（免费即可）。
3. 左侧点项目 → 分别选 `OneGlance` 和 `OneGlanceWidget` 两个 target → **Signing & Capabilities** → Team 选你的 Apple ID（Personal Team）。
   如果提示 bundle identifier 已被占用，把 `Config/Signing.xcconfig` 里的 `BUNDLE_ID_PREFIX` 改成独一无二的值（例如 `com.你的名字`）。
4. iPhone 用数据线连接 Mac，在 iPhone 上开启 **设置 → 隐私与安全性 → 开发者模式**（第一次需要重启）。
5. Xcode 顶部选你的 iPhone，按 ▶︎ 运行。第一次打开前，到 iPhone 的 **设置 → 通用 → VPN 与设备管理** 信任你的开发者证书。
6. 打开 App 后允许访问日历与提醒事项（请选择“完全访问”）。

> 关于“不签名”：iOS 只运行有签名的 App。不签名只能在 Mac 的模拟器（Simulator）里跑，但模拟器里没有你的真实日历。
> 用免费 Apple ID 签名不需要付费，只是 **7 天后会失效**，到时候再用 Xcode 运行一次即可（数据都在系统日历里，不会丢）。
> 若加入 Apple Developer Program（US$99/年），签名一年有效，也可以用 TestFlight 安装。

## 已知限制

- 待办的“预估时长”只保存在本机。提醒事项本身没有时长字段，系统提醒事项 App 里只看得到开始时间。
- 小组件显示所有日历，不会套用 App 里“显示的日历”的筛选设置。原因是这项设置要在 App 与小组件之间共享，需要 App Group，而免费签名不一定支持。
- 重复日程拖动或编辑时只改这一次。
- 订阅日历、节假日日历是只读的，不能拖动。

## 项目结构

```
CalendarApp/
├── OneGlance/                 App（SwiftUI）
│   ├── App/                   入口
│   ├── Model/                 EventKit 读写（CalendarStore）、设置、数据类型
│   └── Views/                 日 / 周 / 月视图、时间轴、快速新增、编辑面板、设置
├── OneGlanceWidget/           小组件与“完成待办”的 App Intent
├── OneGlanceUITests/          模拟器里的端到端 UI 测试
├── Packages/GlanceCore/       纯逻辑（不依赖 iOS，可在 Linux 测试）
│   ├── Sources/GlanceCore/    快速新增解析、时间轴排版、负荷计算、班次
│   └── Tests/                 单元测试
├── Config/Signing.xcconfig    签名设置（Team、Bundle ID 前缀）
└── project.yml                XcodeGen 设置（OneGlance.xcodeproj 由它生成）
```

- 跑核心逻辑测试：`swift test --package-path CalendarApp/Packages/GlanceCore`
- 新增或删除源文件后重新生成项目：`brew install xcodegen && cd CalendarApp && xcodegen`
- GitHub Actions（`.github/workflows/ios.yml`）每次推送都会在 macOS 上编译 App 与小组件、跑核心逻辑测试，并在 iOS 模拟器里跑一遍 UI 自动化测试（`OneGlanceUITests`）：快速新增日程 → 拖动改时间 → 拉底边改时长 → 周 / 月视图 → 排班刷子排一个夜班 → 清单模式新增待办。
- 在 Xcode 里按 ⌘U 也可以在模拟器上跑同一套 UI 测试（会在模拟器的日历里建测试数据，不影响你的 iPhone）。
